# Sleep Tracker

This is a minimal, personal tool built to log daily sleep windows, look at sleep averages, and queue partial logs (like when you just wake up or just go to bed) so you don't forget to track them.

---

## ⚠️ Important Disclaimer

* **Personal Use Only:** This is a private, personal project built specifically for my own workflow and data habits. It is shared purely as-is.
* **NOT Medical Advice:** This application is **not** a medical device, diagnostic tool, or certified health app. 
* **Use Advice Carefully:** The automated feedback, suggestions, and sleep targets generated by this tool are based entirely on basic, general sleep data concepts. They are not absolute truths. Sleep needs are highly individual—use the built-in feedback with caution, listen to your own body over the software, and always consult a real doctor or healthcare professional for actual medical or health concerns.
* **How It Was Built:** This tool was created for my personal tracking using structured data logs from my Google Sheets, with code architected and generated with the help of AI.
